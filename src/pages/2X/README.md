# 🔢 2x

Combine matching tiles to reach as high as score as possible.

## Category

Tile & Spatial

## How to Play

1. Use arrow keys (or swipe) to move all tiles in one direction.
2. Tiles of the same value merge when they collide.
3. Each move spawns a new tile.
4. Get the highest score.
5. The game ends when no moves remain.

## Puzzle Source

**🔧 Generator**

Boards are generated on-the-fly with a seeded random generator for reproducibility.

## Tips & Strategy

- Keep your largest tile in a corner.
- Build rows or columns in one direction to reduce chaos.
- Avoid making moves that break your highest tile's row.
