# 🧵 Crazy Quilt

Arrange the shuffled quilt back into four suit rows from Ace to King.

**Goal:** Sort each row by suit (Spades, Hearts, Diamonds, Clubs) in ascending order (A → K).

## How to Play
1. The deck is shuffled into a 4×13 grid (four rows, thirteen columns).
2. Click two cards to **swap** them.
3. Each row has a target suit shown on the left.
4. Build each row in order from **A to K** for its target suit.
5. **Give Up** reveals the completed quilt layout.

## Tips
- Start by placing the Aces in the correct row.
- Look for cards that already match their target row and rank sequence.
- Use swaps to fix multiple rows at once.

## Accessibility
- All actions can be completed with the keyboard and mouse.
- The current seed is shown so you can replay or share the same puzzle.
