# Grand Tour

## Objective
Fill the 5×5 board with numbers 1 through 25 so each consecutive pair is connected by a legal knight move.

## Rules
- Given clues are fixed and cannot be edited.
- Every number from 1 to 25 must appear exactly once.
- Number `n` and `n+1` must be a knight move apart.

## Controls
- Click a non-given cell to select it.
- Type digits (or use the keypad) to enter values.
- Use **Reset** to clear non-given entries.
- Use **Give Up** to reveal the full tour.

## Generation
Puzzles are generated from a seeded knight's tour and then stripped of clues while preserving uniqueness.
