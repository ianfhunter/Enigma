# Set Square

Set Square is a 3×3 arithmetic placement puzzle.

## Rules

- Fill the grid with the digits **1 to 9**, using each digit exactly once.
- Every row and column has a clue equation.
- Equations are evaluated **strictly left-to-right** (not PEMDAS/BIDMAS).
- A puzzle is solved only when all clues are satisfied.

## Features

- Seeded puzzle generation for reproducible challenges.
- Difficulty levels that change how many starting givens appear.
- Give Up support to reveal the full solution.
