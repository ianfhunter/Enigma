# Spider Solitaire

## How to Play
- Build descending sequences from King to Ace.
- Click a face-up descending sequence to select it.
- Move the selected sequence onto the next higher card or onto an empty column.
- Deal 10 cards from the stock when you need more cards (all columns must be filled first).
- Completing a full King-to-Ace run removes it from the tableau.
- Clear eight runs to win.
- Use **Give Up** to reveal the completed solution immediately.

## Controls
- **Deal 10 Cards**: Adds one face-up card to each column.
- **New Game**: Generates a new seed and reshuffles the deck.
- **Give Up**: Ends the game and completes all runs.

## Notes
- This Spider Solitaire variant uses a single suit for all cards.
- The puzzle is fully reproducible with the displayed seed.
